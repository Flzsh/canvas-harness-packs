# Add-ons & utils

A skill for your AI (Claude, ChatGPT, Codex, Gemini or any assistant that can read files and run Node 22+).

- **Claude**: add this folder as a skill (or upload it to a project) and ask for what you want.
- **Other assistants**: upload the folder or the zip and say "follow SKILL.md".

The scripts in `scripts/` run on your own computer to check and pack what the AI makes. Canvas Harness itself never
downloads code: what you add to it is data (art, colours, poses, settings), checked before it is used.

More at https://flzsh.github.io/canvas-harness-packs/
